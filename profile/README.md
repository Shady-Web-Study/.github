## 🗂️ 레포 규칙
- 레포 이름은 `앱-닉네임` → 예: `lp-dinah05`, `movie-codebidoof`
- 한 레포 = 한 앱! 주차가 바뀌어도 같은 앱이면 같은 레포에서 계속 키워요 🌱

## 🔁 한 주는 이렇게 굴러가요
1. `week05` 처럼 각자 레포에서 **주차 브랜치** 만들기
2. 미션 구현하고 `feat: ...` 형식으로 커밋 - 커밋 메세지 컨벤션은 큰 틀은 지키면서 개인의 취향대로!
3. 마감까지 내 레포 `main`으로 **PR 오픈** 
4. 담당 리뷰어 1명이 리뷰 → 반영 → 머지
5. 모임에서 못 푼 이슈, 리뷰에서 갈린 의견 같이 정리!
